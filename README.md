## About me

For 3 years I hired cloud engineers, Devops, SysAdmins, Backends, Frontends, etc. I knew who was good and why. I just wasn't one of them. That felt like a problem worth solving.

So I went through the Ironhack Cloud & DevOps Bootcamp and built actual infrastructure from scratch. Kubernetes on EKS and AKS, Terraform, Docker, GitHub Actions, Prometheus, Grafana. Not everything worked on the first try. Most things didn't. But when the cluster finally comes up, the pipeline turns green, and everything just runs... that feeling makes it worth it.

AZ-900 certified. Open to infrastructure and cloud roles.

## Projects

### Restauranty — Full Microservices App on AKS
> Restaurant management platform built with a partner as the Ironhack final capstone.

- 4 microservices (auth, discounts, items, React frontend) containerised with Docker and pushed to Azure Container Registry
- Deployed on **AKS** via Helm charts with NGINX Ingress and cert-manager for HTTPS (Let's Encrypt)
- Infrastructure provisioned with **Terraform**, deployments automated through **GitHub Actions**
- Full observability stack: **Prometheus**, **Grafana**, **Loki/Promtail**, SonarQube

[![Repo](https://img.shields.io/badge/View_Repo-161b22?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ireneromero95/devops.restauranty)

---

### MultiStack Infrastructure — Voting App on EKS
> Multi-service voting application deployed on AWS with full IaC and CI/CD.

- 5-service architecture (vote, result, worker, Redis, PostgreSQL) deployed on **EKS**
- Infrastructure provisioned end-to-end with **Terraform**, NGINX Ingress with HTTPS via cert-manager and Route 53
- **GitHub Actions** pipeline for automated deployments
- Resolved real-world issues: EBS CSI Driver IAM misconfiguration, Kubernetes version upgrades, IPv6 binding

[![Repo](https://img.shields.io/badge/View_Repo-161b22?style=for-the-badge&logo=github&logoColor=white)](https://github.com/joaodmorgadoribeiro-del/MultiStack-Infrastructure/tree/main)
